# Runtime dependencies for the FreightIQ backend and data pipeline.
#
# PINS ARE DELIBERATE for scikit-learn and xgboost, not a style choice.
#
# The congestion artifact is a pickle containing a fitted sklearn estimator. Pickles
# are version-coupled: a model fitted on 1.9.1 raises an InconsistentVersionWarning and
# may fail outright on 1.8, and the reverse also fails. The same applies to XGBoost
# boosters. A rebuild on a different version silently produces different walk-forward
# numbers, which is how a headline can move from 18.8% to 20.2% without any code change.
#
# So: exact pins, and the versions are recorded inside the artifacts themselves
# (congestion_model.json carries sklearn_version; freight_metrics.json records the
# model kind and path). models/artifacts/freight_model_card.md reports the regret
# range across seeds, which is what to compare against a rebuild.
#
# Verified on Python 3.14. Python 3.12 was also used and produced the same qualitative
# results, though the exact regret figures move within the seed range.
